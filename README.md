## 📝 Contenido por unidad

### UD1 – Tablas HTML
- **`index.html`** → Ejercicio introductorio de tablas con filas y columnas.
- **`22-01-2026.html`** → Horario semanal completo de 2º GMI con:
  - Tabla de horario con `rowspan` y `colspan`.
  - Leyenda de asignaturas con colores, profesores y fotos.
  - Estilos CSS externos en `estilo/estilos.css`.

### UD2 – Formularios HTML
- **`index.html`** → Resumen con 4 ejercicios de formularios:
  1. Formulario de encuesta (radio, checkbox, textarea, select).
  2. Formulario de datos personales con tabla.
  3. Formulario de CV con fieldsets y selección múltiple.
  4. Formulario de producto con datos económicos.

### UD3 – CSS (Selectores y estilos)
- **`index.html`** → Ejercicio de selectores CSS aplicados a un texto de astronomía:
  - Selectores de clase (`.azul`, `.verde`, `.especial`).
  - Selectores de etiqueta (`a`).
  - Estilos inline con `style`.
